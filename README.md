# Charity Minds

A comprehensive web-based platform designed to manage and track charitable activities, donors, and beneficiaries. Charity Minds simplifies the process of organizing charity operations with a user-friendly dashboard and analytics system.

## 📋 Project Overview

Charity Minds is a charity management system that helps organizations:
- Track registered users and donors
- Record beneficiary information
- Monitor visitor engagement
- Manage communications and messages
- View real-time analytics and statistics

The platform provides an intuitive interface for both administrators and contributors to manage charitable initiatives effectively.

## ✨ Features

- **User Authentication** - Secure login and registration system
- **Dashboard** - Real-time analytics with key metrics:
  - Registered Users count
  - Children Forms Recorded
  - Visitor statistics
  - Message notifications
- **Navigation System** - Easy access to all main sections
- **Responsive Design** - Mobile-friendly interface
- **Logo Branding** - Professional charity branding

## 🛠️ Technologies Used

- **Frontend:**
  - HTML5
  - CSS3
  - Responsive Web Design

## 🚀 Installation

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- A local server (optional, for proper file serving)

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/Brian-Mbogo/Charity-Minds.git
   cd charity-minds
   ```

2. **Open in a browser**
   - Simply open `front/index.html` in your web browser, or
   - Use a local server for better performance:
     ```bash
     python -m http.server 8000
     ```
   - Then navigate to `http://localhost:8000/front/index.html`

## 📖 Usage Guide

### Main Pages

1. **Home Page (index.html)**
   - Welcome landing page
   - Navigation to all platform features
   - Entry point for new visitors

2. **Dashboard (Dashboard.html)**
   - View real-time statistics
   - Monitor key metrics:
     - Registered Users: 10
     - Children Forms: 7
     - Visitors: 56
     - New Messages: 3

3. **Login (Login.html)**
   - User authentication page
   - Secure access to member features

4. **Register (Register.html)**

   - Account creation form

All pages feature a consistent navigation bar with links to:

- Dashboard
- Additional sections
